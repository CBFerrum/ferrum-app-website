# Provenance

This app's design and code are its own. No code was copied from another project.

- Its shape follows what small-company website builders commonly offer: pages and blog posts
  written in Markdown, a menu, a home page, a sitemap and robots.txt.
- It renders on the server on a `site:website` host as Ferrum's Commerce storefront does
  (Ferrum docs/plan/apps-ui.md §7.3); Markdown goes through pulldown-cmark (MIT), with raw HTML
  dropped.
